System Overview

B2C → B2B Expansion
Extends existing TravelPanel user system with a full agent management layer.
Admin Panel manages agents
Approve, suspend, set permissions, manage wallets, review top-up requests.
Agent Panel Modules
Hotels, Flights, Tours, Umrah, Visa — each permission-controlled.
Wallet-based payments
All bookings debited from wallet. Admin credits manually or approves top-up requests.
Permission-based module access
Granular per-agent permissions cached for 60 minutes. Stored in agent_permissions table.
